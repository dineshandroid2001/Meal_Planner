# **App Name**: Roommate Meal Planner

## Core Features:

- User Authentication: Secure user authentication using Google Sign-In.
- Participation Selection: Users can select the number of days they want to join the food plan.
- Admin Cost Setting: Admin can set the total monthly food expense.
- Automated Cost Calculation: Automatically calculate the cost for selected days based on the total monthly expense set by the admin.
- Grocery Reimbursement Tool: Record reimbursements due to roommates who purchased groceries, with details of the purchase and supporting payment screenshots. The LLM can be used to ensure receipts from transactions conform with expected expenditure
- Data Audit Trail: Implement an editable list view showing who edited the data and when it was edited.
- Data Storage and Retrieval: Store and retrieve all data using Firestore database.

## Style Guidelines:

- Primary color: Soft teal (#A0D2EB) for a calm and organized feel.
- Background color: Light beige (#F5F5DC) to provide a neutral backdrop.
- Accent color: Muted orange (#E59866) for important actions and highlights.
- Body and headline font: 'PT Sans', a humanist sans-serif, offering both modernity and approachability.  Note: currently only Google Fonts are supported.
- Use clean, minimalistic icons for food items and actions.
- A clean, intuitive layout optimized for both web and mobile responsiveness, ensuring easy navigation and accessibility across devices.
- Subtle transitions and animations for user interactions, like saving or updating data, to enhance the user experience without being distracting.
